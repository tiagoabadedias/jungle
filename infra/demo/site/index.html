Distributed Wagering Processor — ambiente de demonstração

Serviço financeiro que processa apostas (BET, WIN, LOSS, REFUND, ROLLBACK) por HTTP e SQS, com idempotência persistente, ledger imutável, inbox/outbox e várias instâncias. Este servidor existe só para a avaliação.

Ambiente temporário, aberto publicamente e com dados sintéticos. Será destruído na data indicada acima.

A aplicação não implementa autenticação, conforme decisão documentada no ARCHITECTURE.md (§2 do desafio: autenticação não pontua; ponto de extensão ProviderAuthGuard / ProviderIdentityPort no código). Os endpoints de health são abertos. Nada foi acrescentado na frente da API: é a mesma aplicação da entrega.

As ferramentas de inspeção (banco e filas) são somente leitura: permitem ver tudo, mas não alterar nada.

Verifique o invariante wallet.balance == ledger

Por wallet, pela API 

        
      

      

        Todas as wallets, no banco (aba Query do pgweb)
        
select w.id, w.balance_minor,
       coalesce(sum(case when e.direction = 'CREDIT'
                         then e.amount_minor else -e.amount_minor end), 0) as ledger
  from wallets w
  left join wallet_ledger_entries e on e.wallet_id = w.id
 group by w.id
having w.balance_minor <> coalesce(sum(case when e.direction = 'CREDIT'
                         then e.amount_minor else -e.amount_minor end), 0);
-- nenhuma linha = consistente
